# Website 4: responsive Bootstrap site

A responsive product website for a fictional yogurt brand, built with Bootstrap 4. It is the final project from the course *Web Design Essentials: Zero to Hero*.

**[▶ View it live](https://shzunknown11.github.io/Website-4-responsive/)**

## What's in it

- Hero section, product cards and a founder message, laid out with the Bootstrap grid
- Works on phone, tablet and desktop widths
- `experiment-*.html` and `layout.html`: the practice pages written on the way to the final `index.html`

## Stack

HTML, CSS, Bootstrap 4.3.

## Run locally

Clone the repo and open `index.html` in a browser.
